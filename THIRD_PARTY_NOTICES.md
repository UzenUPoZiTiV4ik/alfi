# сторонние компоненты и данные

## python-пакеты

| пакет | версия | лицензия | зачем |
|---|---|---|---|
| fastapi | 0.162.0 | MIT | http api |
| uvicorn | 0.54.0 | BSD-3-Clause | сервер |
| httpx | 0.28.1 | BSD-3-Clause | запросы к шлюзу и exa |
| pydantic | 2.14.1 | MIT | модели запросов |
| starlette | 1.10.0 | BSD-3-Clause | основа fastapi |
| snowballstemmer | 3.1.1 | BSD-3-Clause | стемминг для поиска |
| pymupdf | 2.0 | AGPL-3.0 / коммерческая | рендер pdf перед ocr (опционально) |

транзитивные зависимости перечислены в `server/uv.lock`: anyio, certifi, click, h11, httpcore, idna, sniffio и другие, все на mit, bsd или apache-2.0.

## модели

все через шлюз организаторов кейса, список разрешённых моделей задан в кейсе.

- `deepseek/deepseek-v4.1-flash` — план, синтез, чат, лента, команда
- `google/gemma-4-26b-a4b-it` — разметка новостей, разбор описания бизнеса
- `z-ai/glm-5.3-flash` — независимый критик
- `qwen/qwen3.6-35b-a3b` — запасная модель
- `qwen/qwen3-vl-30b-a3b-instruct` — ocr сканов вне macos

## шрифты

styrene a lc и styrene b lc — собственность альфа-банка, в репозиторий не входят. без них используется системный гротеск.

## 3d-маскот

кот альфи написан для этого проекта: sdf-фигуры и рэймарчинг на webgl, без библиотек и внешних моделей. вдохновлён маскотами альфа-банка, но геометрия своя.

## данные

- csv компаний, платежей и связей — синтетические данные кейса альфа хака
- 9 pdf аналитики — материалы альфа-банка, предоставлены организаторами
- новости — открытые rss деловых сми и банка россии, в репозитории не хранятся
- exa — внешний поисковый сервис, режимы `search` и `contents`

данные кейса в репозиторий не входят: у каждой команды свои файлы, сервис собирает базу из них при первом запуске.

## смоделированные интеграции

- вход в демо: выбор компании и роли вместо sso альфа-бизнеса
- данные о клиенте: синтетические csv вместо промышленных витрин
- выплаты и группы компаний: расчёт по платежам, а не из справочников банка
